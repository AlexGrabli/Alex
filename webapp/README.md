# CropTalker V2.0 - Система мониторинга датчиков

Веб-приложение для сбора и визуализации данных мониторинга с датчиков по локальной Wi-Fi сети.

## Описание

CropTalker V2.0 - это полнофункциональная система мониторинга агроклиматических параметров, которая собирает данные с датчиков через MQTT протокол и отображает их в удобном веб-интерфейсе.

### Возможности

- 📊 **Отображение графиков** температуры, влажности воздуха и почвы
- 🌱 **Вегетационные индексы** (NDVI, MSAVI)
- ☀️ **Солнечная радиация** (ФАР - фотосинтетически активная радиация)
- 📏 **Высота растений** в режиме реального времени
- 🔄 **Автоматическое обновление** данных каждые 3-5 минут
- 📥 **Экспорт данных** в CSV и TXT форматы
- 📱 **Адаптивный дизайн** для ПК, планшетов и телефонов

## Требования

- Node.js версии 16 или выше
- npm (обычно устанавливается вместе с Node.js)
- Доступ к MQTT брокеру (по умолчанию: mqtt://94.154.11.74:1884)

## Установка

1. Перейдите в директорию приложения:
```bash
cd webapp
```

2. Установите зависимости:
```bash
npm install
```

3. (Опционально) Настройте MQTT брокер:
```bash
export MQTT_BROKER=mqtt://ваш-сервер:порт
```

## Запуск

### Обычный запуск
```bash
npm start
```

### Режим разработки (с автоматической перезагрузкой)
```bash
npm run dev
```

После запуска приложение будет доступно по адресу: `http://localhost:3000`

## Использование

### Веб-интерфейс

1. Откройте браузер и перейдите на `http://localhost:3000` (или IP адрес вашего сервера)
2. Интерфейс автоматически подключится к серверу через WebSocket
3. Данные начнут отображаться после получения первых сообщений от датчиков

### Выбор периода отображения

В верхней части страницы доступен выбор периода:
- Последний час
- Последние сутки (по умолчанию)
- Неделя
- Месяц
- Все время

### Экспорт данных

Кнопки экспорта позволяют скачать данные за выбранный период в формате CSV или TXT:
- **CSV** - для обработки в Excel или других таблицах
- **TXT** - для просмотра в текстовом редакторе

## Мониторируемые параметры

### Климатические параметры
- 🌡️ Температура воздуха (°C)
- 💧 Влажность воздуха (%)
- ⏲️ Атмосферное давление (кПа)

### Параметры освещения
- ☀️ ФАР - фотосинтетически активная радиация (мкмоль/м²/с)

### Вегетационные индексы
- 🌿 NDVI (Normalized Difference Vegetation Index)
- 🌾 MSAVI (Modified Soil Adjusted Vegetation Index)

### Почвенные параметры (3 датчика)
- 🌡️ Температура почвы (°C)
- 💧 Влажность почвы (%)

### Морфометрические параметры
- 📏 Высота растений (мм) - измеряется датчиком расстояния

## Интеграция с устройством

Устройство с прошивкой из файла `Heltec_CropTalker_mqtt_v1_.ino` автоматически отправляет данные на MQTT брокер в следующие топики:

```
CropTalkerData/Tair      - температура воздуха
CropTalkerData/RH        - влажность воздуха
CropTalkerData/Pressure  - давление
CropTalkerData/PAR       - ФАР
CropTalkerData/NDVI      - индекс NDVI
CropTalkerData/MSAVI     - индекс MSAVI
CropTalkerData/Distance  - высота растений
CropTalkerData/Tsoil1-3  - температура почвы
CropTalkerData/SoilWC1-3 - влажность почвы
```

## API эндпоинты

### GET /api/latest
Получение последних данных с датчиков

**Ответ:**
```json
{
  "timestamp": 1699876543210,
  "tair": 22.5,
  "rh": 65.2,
  "pressure": 101.3,
  "par": 450.5,
  "ndvi": 0.75,
  "msavi": 0.68,

  "tsoil3": 18.3,
  "soilwc1": 35.2,

  "soilwc3": 36.1
```

### GET /api/history?period=day
Получение исторических данных

**Параметры:**
- `period`: hour, day, week, month, all

Экспорт данных

**Параметры:**
- `period`: hour, day, week, month, all
- `format`: csv, txt

## Устранение неполадок

### Не подключается к MQTT брокеру
- Проверьте доступность брокера: `telnet 94.154.11.74 1884`
- Убедитесь, что устройство находится в той же сети
- Проверьте настройки Wi-Fi в прошивке устройства

### Графики не обновляются
- Проверьте консоль браузера (F12)
- Убедитесь, что WebSocket подключен (статус "Онлайн")
- Проверьте, что устройство отправляет данные

### Не работает на мобильном устройстве
- Убедитесь, что устройство в той же локальной сети
- Используйте IP адрес сервера вместо localhost
- Проверьте, что порт 3000 доступен

## Безопасность

При развертывании в продакшене рекомендуется:
- Настроить аутентификацию MQTT
- Использовать HTTPS вместо HTTP
- Настроить firewall для ограничения доступа
- Изменить порт по умолчанию
