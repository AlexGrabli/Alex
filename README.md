# CropTalker V2.0 App

Система мониторинга агроклиматических параметров с поддержкой датчиков температуры, влажности, освещения и вегетационных индексов.

## Структура репозитория

### 📱 Прошивка устройства
- `Heltec_CropTalker_mqtt_v1_.ino` - прошивка для ESP32 с датчиками
  - BME280 - температура и влажность воздуха
  - AS726X - спектральные датчики для вегетационных индексов
  - VL53L1X - датчик расстояния (высота растений)
  - Modbus - датчики температуры и влажности почвы
  - Передача данных через MQTT

### 🌐 Веб-приложение
Полнофункциональное веб-приложение для мониторинга данных находится в директории `webapp/`

**Основные возможности:**
- 📊 Графики в реальном времени
- 📱 Адаптивный дизайн для любых устройств
- 📥 Экспорт данных в CSV/TXT
- 🔄 Автообновление каждые 3-5 минут
- 💾 Хранение истории данных

**Быстрый старт:**
```bash
cd webapp
npm install
npm start
```

Подробная документация: [webapp/README.md](webapp/README.md)

## Мониторируемые параметры

- 🌡️ Температура воздуха и почвы
- 💧 Влажность воздуха и почвы (3 датчика)
- ⏲️ Атмосферное давление
- ☀️ ФАР (фотосинтетически активная радиация)
- 🌿 Вегетационные индексы (NDVI, MSAVI)
- 📏 Высота растений

## Технологии

**Устройство:**
- ESP32 (Heltec)
- I2C мультиплексор TCA9548A
- MQTT протокол для передачи данных
- SD карта для локального хранения

**Веб-приложение:**
- Node.js + Express
- SQLite база данных
- WebSocket для real-time обновлений
- Chart.js для визуализации
- Адаптивный CSS дизайн
